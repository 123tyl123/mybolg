# 导数基础知识点
## 1. 导数定义
函数 y=f(x) 在 x₀ 处的导数：
f'(x₀) = lim(Δx→0) [f(x₀+Δx)-f(x₀)] / Δx

## 2. 常用求导公式
- (xⁿ)' = n·x^(n-1)
- (sinx)' = cosx
- (cosx)' = -sinx
- (eˣ)' = eˣ
- (lnx)' = 1/x

## 3. 四则运算法则
- (u±v)' = u'±v'
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv') / v²

## 4. 复合函数求导
y=f(g(x)) → y' = f'(g(x))·g'(x)

## 5. 易错点
1. 常数的导数为0
2. 复合函数一定要逐层求导，不要漏层
3. 注意定义域，lnx 只能 x>0
