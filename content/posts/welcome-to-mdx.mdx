## 为什么用 MDX

MDX 让你在 Markdown 里直接嵌入 React 组件，这非常适合技术博客。

### 功能清单

- 自动读取 `content/posts/*.mdx`
- 根据 frontmatter 生成标题、日期、摘要与标签
- 支持代码高亮、暗黑模式、响应式布局

### 代码片段

```tsx
type PostMeta = {
  title: string;
  date: string;
  summary: string;
  tags: string[];
};

export function sortPosts(posts: PostMeta[]) {
  return posts.sort((a, b) => new Date(b.date).getTime() - new Date(a.date).getTime());
}
```
